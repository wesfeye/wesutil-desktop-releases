# WesUtil

A standalone Kick chat client for Windows: multiple channels in tabs and splits, 7TV/BTTV/FFZ
emotes, the Twitch chat mirror, moderation tools and more.

## Download

Get the latest version from [Releases](https://github.com/wesfeye/wesutil-desktop-releases/releases/latest):

- **WesUtil-Setup-x.y.z.exe**: installer. The installed app updates itself.
- **WesUtil-x.y.z-portable.exe**: runs without installing; it tells you when a new version is out.

The app isn't code-signed yet, so Windows shows "Windows protected your PC" the first time.
Click **More info → Run anyway**.

This repo only holds the release files.
